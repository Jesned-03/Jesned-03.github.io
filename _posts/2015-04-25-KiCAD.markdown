### What is KiCad?
KiCad is a free and open-source software suite for Electronic Design Automation (EDA). It is designed to facilitate the design and simulation of electronic hardware for PCB (Printed Circuit Board) manufacturing. KiCad provides an integrated environment for various stages of the design process, including schematic capture, PCB layout, manufacturing file viewing, SPICE simulation, and engineering calculations.

Step 3 — Install KiCad
Windows:
Double-click the downloaded .exe file to run the installer.
Click Yes to allow changes, then follow the setup wizard.
Leave all default options checked; you can optionally uncheck language packs you don’t need.
Choose the installation folder (default is recommended) and click Install
